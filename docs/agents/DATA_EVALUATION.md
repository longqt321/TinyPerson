# Data and evaluation rules

Audience: AI coding agents.

## Data

- MSR experiments use `/mnt/data/tinyperson_official_v1/data.yaml` in the
  Modal Volume `tiny-person-data`.
- Current split: 746 images, 662 train and 84 validation.
- Do not edit the original dataset. The YOLO derivative is generated by
  `scripts/prepare_tinyperson_yolo.py`; keep `manifest.json` for split tracking.
- Dataset preflight checks images, labels, COCO dimensions, and the dataset
  signature. Passing preflight does not prove the split is scientifically good.
- Do not commit datasets or generated derivative files.

## Three evaluation levels

Do not mix these results:

1. YOLO validation on the derivative: use it to select checkpoints between runs.
2. COCO AP-small on original images: use `scripts/evaluate_coco_small.py`; it
   needs original annotations, `manifest.json`, and `pycocotools`.
3. Official TinyPerson benchmark: use original images and annotations with
   `scripts/predict_tinyperson_test.py` and
   `scripts/evaluate_tinyperson_benchmark.py`.

The derivative validation split is not a test set. Do not call it test.

## Reporting rules

- Select models on validation, never on official test.
- Report metrics from the `best.pt` checkpoint, not the final epoch.
- Do not report AP-small or official test results until the relevant script has
  run successfully on a specific artifact.
- The TinyPerson evaluator in this repo is not a vendored reference evaluator.
  Miss rate still requires the reference evaluator.
- A single seed or W&B curve is not evidence that MSR improves detection.
  See `docs/MSR_P2.md` and `docs/modal_results_2026-10-20.md` before claiming a
  result.
