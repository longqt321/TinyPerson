# Literature search strategy

## Six required layers

| Layer | Search target |
|---|---|
| L0 Direct | Same task, method, and dataset |
| L1 Core technique | Each mechanism used by proposed method |
| L2 Mathematical foundation | Relevant theory: optimization, information theory, statistics, linear algebra, etc. |
| L3 Original work | Introductions and seminal sources for key concepts |
| L4 Adjacent field | Analogous ideas in statistics, control, physics, economics, neuroscience, or other fields |
| L5 Critiques/failures | Limitations, negative results, failure cases, generalization critiques |

## Search procedure

- Use English queries, 2–6 words each; run at least two distinct queries per layer.
- Start broad, then narrow. Avoid near-duplicate queries.
- For each core source, inspect its references and citing works when tools permit. Search title plus `cited by` or `references` otherwise.
- Classify each source as core, foundational, analogous, or peripheral. Exclude peripheral work.
- Add one sentence explaining how each included source informs this specific study.
- Verify title, authors, year, venue, and factual claims against a primary source (publisher, conference, DOI record, or arXiv). Do not infer content from title alone.
- Note when primary text was not read. Do not make claims about unread work.
- Stop after all six layers have queries and two consecutive search rounds produce no new core or foundational source. Record empty layers and queries tried.
- Record failed search tools/servers and queries in `00_state.md`; do not silently repeat a broken route.

Never invent DOI, venue, author, or citation metadata. Keep unresolved records marked `[CẦN XÁC MINH]` and out of strong claims.
